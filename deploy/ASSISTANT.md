# Desktop AI 对话

AI 请求在 Desktop Agent 发起，模型密钥只存在于 Desktop 进程环境；手机与 Desktop 之间复用已认证的加密通道。Server 不接收模型密钥，也不解密对话或终端内容。

在启动 Desktop Agent 的环境设置：

```sh
export AI_TERMINAL_AI_BASE_URL=https://your-model-provider.example/v1
export AI_TERMINAL_AI_MODEL=your-model-name
# 从本地私有凭据管理工具注入 AI_TERMINAL_AI_API_KEY，不把真实值提交到代码或文档。
ai-terminal
```

端点使用非流式 `POST /chat/completions`，支持 HTTPS 或本机回环 HTTP。解释与监控需要文本 messages；开启“允许操作”还要求模型支持 function tools。现有 Agent 不会重新读取新环境，需要在结束/保存当前工作后重启 Agent，重启会关闭其 Shell，因此不要在运行任务时为应用配置直接停止它。

未设置端点或模型时 App 显示未配置；配置格式不合法、网络失败、服务拒绝、超时会显示实际错误状态，不伪造答案。密钥为空仅适用于允许匿名访问的本机模型服务；远程服务通常需要密钥。

手机在半透明 AI 浮窗发送消息，可选择“允许操作”和“监控当前终端”。监控开启时，本次消息、有限前文与当前终端屏幕会发送至配置的模型供应商；之后根据屏幕变化继续观察。不会读取其他终端、任意文件或全盘数据。屏幕为有界快照，可能截断。

明确要求操作当前终端并开启“允许操作”时，模型可以调用一次 `terminal_input`：单行文本与是否发送 Enter 为独立字段，例如输入 `ls /Volumes/Code` 并回车。客户端取得当前会话控制，Desktop 在真正入队前重新校验账号、会话、控制 epoch 和人工输入序号。期间人工输入、抢占或切会话会拒绝过期 AI 输入。模型不能调用其他工具，不能直接读写文件；终端输入本身仍可执行 Shell 命令，请只在预期的会话发送任务。

输入入队事件不等于命令完成。监控按实际终端 revision 变化产生事件，再由模型给文字说明；屏幕静默或模型推测不作为确定成功证据。只有终端进程本身结束时可报告该会话的退出码。事件带 request ID、单调事件 ID 与 revision，手机去重保存。

关闭聊天浮窗后已接受的监控继续运行；可点停止监控，停止不会发送 Ctrl-C，也不能撤回已经入队的输入。Ctrl-C 有独立工具按钮。单次监控最多 5 分钟或 30 次模型观察，达到上限明确暂停，重新发消息可继续。语音识别只填草稿，不自动发送。

手机保存按服务、账号、设备和会话隔离的对话历史。Desktop 仅在内存保留最近 64 个请求结果，完成结果最长保留一小时；最多同时运行 4 个工作任务，新消息替换当前终端旧监控。每次模型请求最多等待 60 秒，可取消。断线后可用原请求 ID 查询；Agent 重启或结果过期不会自动重放旧请求。新输入/监控字段要求升级 Desktop 与手机原生库。

自动化使用本地模型桩验证 function tools 合同、加密移动通道、真实 PTY 输入与监控、去重、控制权失效、人工抢占和取消；确定性测试模型会明确标识。实际供应商的模型兼容性、限流与响应质量需以其配置为准，不将测试模型结果称为真实线上模型验收。
