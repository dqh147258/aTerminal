# 工具操作详情改版

用户要求优化工具详情的整体 UI，调用参数与结果采用展开方式，不使用小弹窗。

## 实现
- 新增 `ToolDetailsPage.kt`：不透明全屏详情页，固定返回栏。工具名称、真实状态、时间和摘要分层展示；参数、结果、关联记录分别使用可独立展开的区域。
- 展开后原位读取完整记录。JSON 缩进排版，文本等宽显示，长行支持横向滚动；可选择文字和复制完整原文。图片记录原位显示。完整事件 JSON 放入默认折叠的“完整记录”。
- 记录按原协议分页读取，保留 4 MiB 记录边界；超过限制或请求失败明确显示错误，不静默截断。失败在对应区域重试；同页收起再展开复用已读取内容。
- `AgentPanel.kt`：聊天中的工具入口改为紧凑的摘要行与右箭头；详情页与聊天共享原会话请求身份。读取结果只能更新发起它的详情页；关闭页面后迟到回调不会弹窗或写入聊天。打开详情不会把聊天中的新消息误标已读。
- `MainActivity.kt`：系统返回优先退回聊天；草稿、消息阅读位置保留。普通回复全文/Markdown 逻辑不变。
- `ToolDetailsUiTest.kt` 与现有 UI/E2E 测试更新到新交互。
