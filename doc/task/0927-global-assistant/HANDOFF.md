# 交付及可选设备确认

代码与自动化验证已完成。使用新功能时需同时更新 APK 和 Desktop；旧 Desktop 不支持新增全局会话接口，会如实显示同步/创建失败。

推荐在常用手机和真实模型上确认：
1. 从右侧全局AI助手入口新增两个会话，在第一个发送任务后返回列表。其执行标记应来自真实任务，收到回复后显示未读；打开第二个不应清除第一个未读。
2. 打开历史会话并向上阅读，返回再进入应保留位置；滚到最新回复后清除未读。关闭 App 重开后历史与草稿仍保留。
3. 检查旧全局历史出现在独立列表，终端气泡只显示对应 Session；返回依次是列表、首页。
4. 在真实输入法和麦克风上确认图片/语音输入；退出会话时取消语音识别，迟到识别文本不进入其他会话。

这些属于实体设备体验确认，不影响已完成的实现与自动化验收。端到端测试使用本地确定性模型，未进行付费模型质量评估。
