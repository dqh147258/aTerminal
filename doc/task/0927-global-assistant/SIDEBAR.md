# 工作空间侧边栏调整

参考：`/Volumes/Code/OpenDesignProjects/4c6b6741-85d2-4ded-b4c0-37377166a5c9/screenshot-2026-09-27T12-51-23-715Z.png`。

- 侧栏宽度改为手机可用宽度的 92%，大屏仍限制最大宽度。
- 顶部工作空间标题、匹配会话数量、加号和关闭按钮；独立搜索框和“所有会话”刷新行。
- 会话条目分为终端/归档图标、目录名称、完整路径（长路径省略）与真实状态/设备。当前会话显示背景、边框和勾选；当前及在线会话优先显示。标题使用现有数据中的目录名，不注入原型演示名称。
- 移除每行单独的对话气泡；在线条目继续打开终端，离线或桌面离开的条目继续打开对应历史。可关闭的在线终端保留关闭按钮和原确认流程。
- 账号头像/名称及账号与设备入口固定在底部；搜索和刷新不会重建终端。旧手机归档入口按后续用户要求移除。
- 新增同套线性图标，保持原生无障碍名称和当前项选中状态。

修改：`MainActivity.kt`、五个 drawable 图标，以及现有 `MobilePrototypeTest.kt` 的侧栏回归场景。

验证：Android APK、测试 APK 和 lint 构建；侧栏搜索、数量、高亮、状态、关闭入口、离线历史、终端对象保留，以及独立全局助手返回导航回归。日志及截图位于 `artifacts/workspace-sidebar/`。

## 后续移除旧手机归档

按用户要求删除 Android 侧栏的旧手机归档入口与 `LegacyAgentHistory.kt`，Android 不再提供旧手机归档导入或展示。正常 Desktop 会话及全局AI助手历史沿用现有实现。未改动仍供 iOS 使用的共享归档接口。构建、lint 与侧栏回归通过，最新截图与日志见 `artifacts/remove-legacy-archive/`。
