# Android 真机验证结果

日期：2026-09-22。设备为用户常用 M2012K10C（ares），Android 12 / API 31，arm64-v8a，1080×2400，440dpi，本次显示模式 60Hz。设备使用搜狗小米版输入法。

后续一致性优先的优化与新一轮固定节拍对照见 [FOLLOWUP.md](FOLLOWUP.md)。本文保留首轮真机数据，不覆盖历史结果。

## 结论

账号登录、设备发现、真实 PTY 输入、WebRTC direct、USB 回环中转、Ctrl-C、退到桌面后恢复及退出均通过。三种负载各 1,000 字符完整回显，未丢失或重复。原生 EditText 按键/删除和 InputConnection 中文/Emoji 提交通过。

发现 Android 绘制开销后增加按行 RenderNode 缓存（Android 29+，旧系统保留 Canvas 路径）、相同样式 ASCII 批量绘制、关闭 ASCII ligature；断开时清空旧会话按钮，避免新连接完成前操作旧列表。构建脚本新增 `--release`，本机已安装的 APK 使用优化编译的 arm64 Rust 库，App 本身仍是可调试版本。

改善了整帧耗时，但**真机整帧 p95 尚未达到 16.7ms，不能宣称完全无卡顿**。持续输出时本地编辑事件仍有约 22ms 的 p95，远端回显有 100ms 以上尾延迟。需要继续按真实网络、调度、FFI 与 UI 帧阶段分析，不能用此前模拟器离屏绘制指标代替真机整页体验。

## 网络与采样

- 手机 Wi-Fi 地址为 192.168.0.12，主机为同一局域网。账号/协调服务使用 `adb reverse` 到独立回环服务；标记为 direct 的终端数据走 WebRTC，USB 只承担协调控制链路。
- relay 验证使用 USB 转发的回环 WS + Noise，**不是公网 WSS/TLS、TURN 或蜂窝测试**。未模拟真实丢包。
- 输入回显从 `sendText` 入队前的单调时钟开始，到包含该字符的 ViewTreeObserver 绘制回调结束计时；并非像素显示完成时间，也不包含此前输入法组合阶段。
- FrameMetrics TOTAL_DURATION 为整个窗口帧，DRAW_DURATION 是窗口绘制阶段，包含测试观察回调开销。每种负载有 1,000 个字符及 60 个原生按键事件；发送间隔目标 10ms，实际主线程调度会延长。
- 本地编辑事件从注入按键前到 TextWatcher 回调，不是手指触摸到像素呈现的测量。
- 真机插 USB 充电，系统后台应用与温度未被控制。thermalservice 缓存曾报告状态 3，而实时 HAL 皮肤温度约 40–43°C、状态 0；因此前后差异不应全部归因于单项代码改动。

最终三组输入到绘制回调的 p50 为 31.28 / 39.77 / 37.41ms，p99 为 130.91 / 195.35 / 151.07ms。App PSS 约 97–107MiB，含测试 instrumentation、原生库、窗口等，不代表正式 Release App 的独立资源占用。

行缓存单独改善空闲绘制；持续输出改善主要出现在原生库改用 Release 之后。由于未对系统温度、后台负载做严格控制，不能作为单因素因果实验。本地编辑 p95 并非所有场景均改善，报告保留实际数字。

## 功能证据

- `instrumentation-final.log`：完整功能与三组压力测试，`OK (1 test)`，约 60.6 秒；详细数字在 `results-final.json`。
- `guarded-smoke-2.log`：用户指出误触后，加入目标 Activity/前台焦点检查重跑，`OK (1 test)`，约 5.8 秒；包括实际 Home 后恢复，不仅直接调用生命周期函数。
- `sogou-results.json`：设备自带搜狗键盘曾通过触摸组合/候选提交“你好”；截图为 `sogou-composition.png`、`sogou-commit.png`。这是一次功能验证，没有软键盘触摸延迟统计。
- UI 内 `printf` 的独立输出、Ctrl-C 解除 `sleep`、接管后输入和注销可见；测试没有把输入 ACK 当作命令完成。
- `guarded-build.log` / `final-build-lint.log`：App、测试 APK、lintDebug 成功；lint 尚有 DrawAllocation 等警告，并非零警告。
- `fixture-clippy.log`：新增隔离负载夹具 clippy `-D warnings` 通过。Python 构建脚本语法检查通过。

首轮后台恢复探针存在等待旧会话列表/控制权就绪的竞态，后续改为等待本次选择与 UI 控制状态完成，并用真正 Home/启动恢复验证。中途测试服务随会话中断退出，导致一次登录网络错误；重建隔离服务后前台保护复测通过。这些失败不记作通过，也不当作 App 崩溃。

## 误触与设备操作

用户指出后续坐标操作误开其他应用，已手动退到桌面。不能用账号测试曾成功来否认该误触。已停止外部键盘坐标脚本，移除测试代码中等待外部坐标的 keyboard 模式；按钮操作和键事件前校验本应用活跃且有焦点，失去前台则停止。

常用测试设备会自动锁屏、无密码，按电源键后上划解锁；自动化用 WAKEUP 避免关闭已亮屏幕。完整操作规则已保存到 [deploy/ANDROID-DEVICE.md](../../../deploy/ANDROID-DEVICE.md)。没有修改系统锁屏超时、输入法选择或其他 App 配置。

## 剩余范围

尚未验证真公网 WSS/TURN、蜂窝、实际丢包、横屏布局完整矩阵、其他 Android 版本与低端设备。16.7ms 整帧目标及持续输出时本地编辑尾延迟仍是后续性能优化项。现有测试证明功能可用和相对改善，不是全部性能验收达标。

验证结束已注销临时手机账号、关闭本次隔离服务和 Agent、删除本次 ADB 转发及临时登录凭据。手机保留优化版开发包，最后确认前台为 AI Terminal 未登录界面，未继续操作其他应用。
