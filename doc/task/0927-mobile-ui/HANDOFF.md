# 设备确认与交付

实现与自动化验证已完成；以下为可选的真实环境确认，不阻塞代码交付。

1. 更新 Desktop 与 Android APK，选用配置中明确声明支持图片的模型；发送一张截图及问题，确认模型实际解读图片。仅验证是否理解图片，不必让模型修改终端文件。
2. 在常用实体设备/输入法上打开聊天键盘，旋转屏幕，放大系统字体；输入框应保持可见，草稿与附件保留，向上阅读位置不被新回复打断。
3. 授权麦克风后开始语音输入，切换 Session / Global；录音应停止，迟到识别文字不得进入另一作用域。
4. 在选中终端执行普通 `cd`，约 3–5 秒后聊天标题应更新为当前路径；Global 仍显示同一个选中终端的路径。

图片调用与当前路径新增能力需要匹配的 Desktop 版本。未做生产部署、真实付费模型调用或用户账号配置修改。
