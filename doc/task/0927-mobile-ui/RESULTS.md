## 实现

- 设置改为全屏半透明页面，分组进入 LLM 大模型、终端读取、MCP、Skills 与账号设备；显示恢复仅影响字号和不透明度。LLM 页面保留配置修订、密钥留空保留、目录选择和模型绑定，提供独立默认绑定与折叠高级参数；MCP JSON 可编辑。
- 聊天标题直接切换 Session / Global；当前选中终端目录通过 Desktop 的实际进程观测更新。长路径点击查看全文，缺失时如实显示。打开浮层不重建终端。
- 紧凑输入包含 16dp 图片/语音图标与同位置发送/追加/停止。默认允许 Agent 操作，业务授权仍由 Desktop 检查；取消请求后保持取消中直到服务端确认。
- 按服务器、账号、Desktop、会话保存文字和图片草稿、请求 ID、历史链、阅读位置与工具展开状态；切换作用域不取消任务。语音切换时取消，并以世代标识忽略迟到识别结果。
- 历史按时间连续展示，上滑分页保持阅读锚点，新消息不夺取输入焦点或强制滚到底。工具与证据默认折叠，“最新消息”悬浮在消息区。
- 系统图片选择器、URI 粘贴、预览、移除、纯图片和图文消息；私有文件保存图片，配置仅存引用。Desktop 分块接收、按作用域验证、事务保存二进制记录，模型请求使用真实图像内容字段。缓存有容量清理，暂存上传支持释放与过期。
- 统一侧栏按设备/会话标识去重，显示真实在线、已关闭、Desktop 离开等状态；离线项直接只读打开记录，保留搜索、新建、关闭确认、旧归档及账号入口。缓存曾读取的会话目录。

## 兼容与验证边界

- 图片与动态进程目录需要同时更新 Desktop。纯文字请求不添加新字段，继续兼容旧 Desktop 的严格消息解析；旧 Desktop 目录接口不可用时显示“路径不可用”。
- 使用既有记录上限：每张 4 MiB、每条最多 4 张/合计 8 MiB，UI 明确说明；未沿用原型较大的演示限制。
- 图片端到端验证使用隔离的可控模型 HTTP 服务，证明真实图文数据流；未调用用户付费供应商进行图像理解质量评估。
- 模拟器 Gboard 使用硬件键盘/手写工具条模式；已验证实际 Insets 调整及额外的严格可用高度约束。不同输入法的完整软键盘外观、真实麦克风识别效果和实体设备体验仍建议按 HANDOFF.md 做设备确认。
- 会话内容搜索覆盖手机已读取缓存，不将未下载的远端历史伪装为全量搜索。
