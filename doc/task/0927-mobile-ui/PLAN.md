# Android 原型 UI 落地

- Status: Completed
- Updated: 2026-09-27

## 目标与范围
按用户指定 UI_IMPLEMENTATION_GUIDE.md 实现 Android 登录后 UI；登录页不修改。保留原生终端、认证、控制权、配置修订和证据语义。图片必须进入真实模型请求。

## 当前状态与证据
NativeUi.kt 已有雾蓝主题。AgentPanel.kt 有旧导航、权限勾选、纯文字提交与倒序历史。MainActivity.kt 设置浮窗与双标签侧栏需要重组。AgentSettingsPanel.kt 已有真实配置服务。runtime.rs 的 Send 仅支持文字；Agent RPC 上限 65536 字节，Store 单记录上限 4 MiB，需分块上传并引用二进制记录。

## 方案与执行
用户已明确授权按完整交接指南执行，沿用其中顺序。
1. 设置全屏、拆分 LLM/读取/MCP/Skills 页面、统一会话列表。
2. 聊天直接作用域切换、动态路径、独立持久草稿、连续历史与阅读锚点、同位置发送/追加/停止和语音。
3. 图片使用系统选择器与本地私有文件，分块上传到 Desktop；记录引用进入历史和模型视觉内容；保留草稿处理失败。
4. 构建、关键状态/协议回归、现有 Android 模拟器 UI 验证。

## 验证
运行 Rust 图片协议/运行时测试、Android 构建及关键 instrumentation 测试。使用现有模拟器核验设置、聊天、键盘和横竖屏。外部视觉供应商若无可用配置，明确记录验证边界，使用模型请求边界测试核对图文内容。

## 风险与回退
图片接入跨 Desktop 与 Android，需部署匹配版本。采用既有记录 4 MiB 单图上限、4 张/8 MiB 总量，避免扩大所有证据限制。变更以单独文件/明确修改块回退，保留历史缓存。

## 执行结果
全部步骤完成；Android 构建与 lint、54 项 Rust 测试、Android 16 UI 回归及图文端到端验证通过。详见 RESULTS.md；真实供应商图像理解和实体设备语音体验见 HANDOFF.md。真实目录测试最初因沙箱禁止 ps 失败，在经自动审批允许进程观测的隔离测试中通过。
